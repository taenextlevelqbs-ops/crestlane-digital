# Infrastructure & Security Labs

This section contains safe, publicly shareable **example lab material** supporting the [engineering portfolio](../engineering-portfolio.md).

These examples are not employer configurations, production environments, certifications, proof of deployment, or claims of tested infrastructure.

## Examples

- [Windows System Health Audit](windows-system-health-audit.ps1): read-only PowerShell script for a local or authorized Windows lab machine.
- [Azure Landing Zone Plan](azure-landing-zone-plan.md): architectural checklist for a future personal Azure lab using synthetic resources.

## Safety principles

- Run scripts only on systems you own or are authorized to manage.
- Use fictional or synthetic hostnames, accounts and datasets.
- No government, client, or employer operational materials are included.
- No credentials, secret keys, private topology or actual inventory exports should be committed.

## Testing

The PowerShell example is intentionally read-only, but has **not been executed against a Windows host** as part of publishing this documentation. Test it in an isolated local environment first.
